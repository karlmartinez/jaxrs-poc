# jaxrs-poc

A practice project built around concepts from *RESTful Java with JAX-RS 2.0* (O'Reilly) — the same book that grounded the JAX-RS approach on a client project I worked on as a junior Java developer.

On that engagement, I helped build the first-market release: development, code reviews, and integration with client-facing applications. I later moved to a follow-on phase supporting additional market integrations and later changes. The project shipped successfully and came in under budget.

This repo is where I revisit and practice the same JAX-RS patterns outside of client work — resource classes, request/response handling, and REST API design.
